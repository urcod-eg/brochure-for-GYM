# Gym management — brochure (urcod)

One static page: `index.html` + the `assets` folder. No build step.

Publish on GitHub Pages: upload both to a new public repository, then
Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.

WhatsApp/Facebook card: after the first publish, change the `og:image` line in
`index.html` to the full link, e.g. `https://USER.github.io/REPO/assets/og.jpg`.

Fonts: Cairo and Bebas Neue, SIL Open Font License (assets/fonts/OFL-Cairo.txt).
